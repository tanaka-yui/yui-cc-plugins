# codex-bridge

Claude Code の rules / CLAUDE.md を Codex 用 `AGENTS.md` にネスト生成する汎用プラグイン。

## 仕組み

- `.claude/rules/*.md` の frontmatter `codexTargets: [<dir>/, ...]` を正として、各 `<dir>/AGENTS.md` を生成。
- root `CLAUDE.md` → root `AGENTS.md`。
- `--global`: `~/.claude/CLAUDE.md` → `~/.codex/AGENTS.md`。
- 生成物は先頭に `GENERATED by codex-bridge` センチネルを持つ。センチネル無しの既存 `AGENTS.md` は手書き扱いで上書きしない。
- Codex の `project_doc_max_bytes`（既定 32KB）超過は警告のみ。分割は `codexTargets` をより深いディレクトリに割り当てて対応する。

## 開発

```bash
bun test              # src/generate.test.ts
pnpm --filter @tanaka-yui/codex-bridge check
```

ロジックは `src/generate.ts` の純粋関数（parse / render / group / decide / size）と、fs を触る収集・書き込み・main に分離されている。純粋関数を優先して TDD する。

## 関連プラグインとの境界

cmux 系プラグイン（cmux-team 等）とは責務が独立。本プラグインは「Claude 設定 → Codex 設定」の一方向変換のみを担い、cmux トポロジや実行オーケストレーションには関与しない。
