Request each review with ONE call to agmsg `send.sh`: `~/.agents/skills/agmsg/scripts/send.sh <team> <your agent name> <Review pane agent> 'review-code: <request text>'`. The recipient is the Review pane agent printed in the header, never a surface or workspace id, and a non-zero exit means the reviewer was NOT told, so report it instead of polling for a verdict that can never appear. Read `reviewer_engine` from the review configuration; it must be the Review engine printed in the header, and you must never derive it from another role. Resolve the reviewer pane surface from the `review` entry of the prewarm.json in the status directory for the liveness check only. Never deliver a message by typing it into a pane yourself. Capture a reviewer screen baseline, and at 15-minute boundaries compare a fresh capture; retry screen observation three times at 10-second intervals. An unchanged live pane is stalled; two consecutive all-failed observations are also stalled. Re-send the same round once after a stall, then record a skipped review and proceed if it stalls again.

If you stop before completing the work, do not stop silently. Write the reason to the round findings file with a last line of `VERDICT: needs_work`, tell the reviewer with one more `send.sh` call that is identical to the review request except that the body starts with `abort-reviewer: [abort]` followed by a one-line reason, write status `error` with the reason as message, then notify the parent with one final `send.sh` call addressed to the `parent` agent whose body starts with `dispatch-notify:`, and end the session. Writing the status file alone notifies no one.
