# cmux-e2e Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** cmux 内蔵ブラウザ（`cmux browser` CLI）を使った E2E テスト実行基盤を、新規プラグイン `apps/cmux-e2e` として追加する。

**Architecture:** bash のみのプラグイン。`skills/cmux-e2e/scripts/` に 4 本の CLI（`up` / `auth` / `run` / `down`）、`scripts/lib/` にロック・サーフェス解決・認証の locked core を置く。制御用の状態（サーフェスレジストリ・認証ステート・ロック）は `~/.cache/cc-skills/cmux-e2e/<project>/` に置き、成果物だけ worktree 内の `.cmux-e2e-results/` に置く。

**Tech Stack:** bash（`#!/usr/bin/env bash` / `set -euo pipefail`）、`cmux` CLI 0.64.22、`jq`、`shasum`。追加の依存は入れない。

**Spec:** `docs/superpowers/specs/2026-08-25-cmux-e2e-design.md`

## Global Constraints

- `apps/e2e-test` に一切差分を出さない。並存させる
- `--engine cmux|agent-browser` のようなバックエンド切替を作らない
- `~/.agents/skills/cmux-browser` と役割を重複させない（あちらは操作プリミティブ、こちらはテスト実行基盤）
- バージョンは `1.0.0`。`apps/cmux-e2e/.claude-plugin/plugin.json` / `apps/cmux-e2e/.codex-plugin/plugin.json` / ルート `.claude-plugin/marketplace.json` の 3 箇所で一致させる
- `package.json` は作らない（bash のみのプラグインは全て持っていない）
- `skills/cmux-e2e/SKILL.md` は frontmatter を除き日本語を含めない。`## Output Language` ブロックを frontmatter 直後・H1 より前に置き、本文 3 行を逐語一致させる。`skills/cmux-e2e/references/guide-ja.md` を必ず用意する（H1 が先、`## Output Language` が後）
- `CLAUDE.md` / `README.md` は日本語
- スクリプトは `#!/usr/bin/env bash` + `set -euo pipefail`、mode 755、終了コードは **2 = 使用法/検証エラー、1 = 実行時失敗、0 = 成功または無害な no-op**
- `cmux browser` は**常に `--surface <ref>` をフラグ形式**で渡す。セレクタ・テキスト・キーもフラグ形式（`--selector` / `--text` / `--key`）
- 合否は exit code で分岐する。stderr を JSON として解析しない
- `wait` のタイムアウトは `--timeout-ms` に統一する
- **`cmux browser ... import` をどの経路からも呼ばない**（無引数だと破壊的。実測で 3808 件の cookie を取り込んだ）
- `trace` / `screencast` / `viewport` / `network` / `offline` / `geolocation` は `not_supported` なので使わない
- ロックは `mkdir` の atomic 性だけに依存する。`owner.json` は診断用で排他の判定に使わない。**stale ロックの自動回収はしない**
- 全ディレクトリ `0700` / 全ファイル `0600`
- コミットは `<type>(cmux-e2e): <日本語の要約>` 形式。末尾に `。` を付けない

```bash
#!/usr/bin/env bash
# common.sh — project key / worktree key の解決とパス検証。
# このファイルは source される。set は呼び出し側の設定に従う。

cmux_e2e_die() { echo "cmux-e2e: $1" >&2; exit "${2:-1}"; }

# 名前として使える文字だけを許す。名前中の . は許すが . と .. 自体は拒否する。
cmux_e2e_validate_name() {
  local n="${1-}"
  [[ -n "$n" ]] || return 2
  [[ "$n" != "." && "$n" != ".." ]] || return 2
  [[ "$n" =~ ^[A-Za-z0-9._-]+$ ]] || return 2
  return 0
}

_cmux_e2e_sha256_16() { printf '%s' "$1" | shasum -a 256 | cut -c1-16; }

# worktree の canonical realpath から 16 桁の鍵を作る。
cmux_e2e_worktree_key() {
  local root
  root=$(git rev-parse --show-toplevel) || return 1
  root=$(cd "$root" && pwd -P)
  _cmux_e2e_sha256_16 "$root"
}

# project key: .dev-up.yaml の project があればそれ、無ければ
# <git common dir の親ディレクトリ名>-<realpath(git common dir) の SHA-256 先頭 16 桁>
cmux_e2e_project_key() {
  local root common main name key
  root=$(git rev-parse --show-toplevel) || return 1
  if [[ -f "$root/.dev-up.yaml" ]] && command -v yq >/dev/null 2>&1; then
    key=$(yq -r '.project // ""' "$root/.dev-up.yaml" 2>/dev/null || echo "")
    if [[ -n "$key" && "$key" != "null" ]]; then
      cmux_e2e_validate_name "$key" || return 1
      printf '%s' "$key"; return 0
    fi
  fi
  common=$(git rev-parse --git-common-dir) || return 1
  case "$common" in /*) ;; *) common="$root/$common" ;; esac
  main=$(cd "$(dirname "$common")" && pwd -P) || return 1
  name=$(basename "$main")
  key="$name-$(_cmux_e2e_sha256_16 "$main")"
  cmux_e2e_validate_name "$key" || return 1
  printf '%s' "$key"
}

cmux_e2e_cache_root() { printf '%s/.cache/cc-skills/cmux-e2e' "$HOME"; }

# 経路上に symlink があれば拒否する。存在しない末端は親まで遡って確認する。
cmux_e2e_reject_symlink() {
  local p="$1"
  while [[ -n "$p" && "$p" != "/" ]]; do
    [[ -L "$p" ]] && return 1
    [[ -e "$p" ]] || { p=$(dirname "$p"); continue; }
    p=$(dirname "$p")
  done
  return 0
}

cmux_e2e_mkdir_secure() { mkdir -p -m 700 "$1"; }

# 一時ファイルから所定のパスへ 0600 で置き換える。
cmux_e2e_install_file() {
  local tmp="$1" dest="$2"
  chmod 600 "$tmp" && mv -- "$tmp" "$dest"
}
```

```bash
#!/usr/bin/env bash
# lock.sh — mkdir の atomic 性だけに依存するロック。自動回収はしない。
# owner.json は診断用の情報であり、排他の判定には使わない。

cmux_e2e_lock_acquire() {
  local dir="$1" parent tmp
  parent=$(dirname "$dir")
  cmux_e2e_mkdir_secure "$parent"
  if ! mkdir -m 700 "$dir" 2>/dev/null; then
    local info="unknown holder"
    if [[ -f "$dir/owner.json" ]] && command -v jq >/dev/null 2>&1; then
      info=$(jq -r '"pid=\(.pid) started_at=\(.started_at)"' "$dir/owner.json" 2>/dev/null || echo "unreadable owner.json")
    fi
    {
      echo "ERROR: could not acquire lock ($info)."
      echo "  If no cmux-e2e command is running, remove the lock directory:"
      echo "    rm -rf $dir"
    } >&2
    return 1
  fi
  tmp="$dir/.owner.json.tmp.$$"
  printf '{"pid":%d,"worktree":"%s","started_at":"%s"}\n' \
    "$$" "$(git rev-parse --show-toplevel 2>/dev/null || pwd)" "$(date -u +%Y-%m-%dT%H:%M:%SZ)" > "$tmp"
  cmux_e2e_install_file "$tmp" "$dir/owner.json"
  return 0
}

cmux_e2e_lock_release() { rm -rf -- "$1"; return 0; }
```

```bash
#!/usr/bin/env bash
# surface.sh — tree --all によるサーフェス解決。短 ref ではなく UUID を主キーにする。

CMUX_BIN="${CMUX_BIN:-cmux}"

cmux_e2e_surface_registry_path() {
  printf '%s/%s/surfaces/entries/%s.json' \
    "$(cmux_e2e_cache_root)" "$(cmux_e2e_project_key)" "$(cmux_e2e_worktree_key)"
}

cmux_e2e_surface_lock_dir() {
  printf '%s/%s/surfaces/locks/%s' \
    "$(cmux_e2e_cache_root)" "$(cmux_e2e_project_key)" "$(cmux_e2e_worktree_key)"
}

# rc 0=解決 / 10=A / 11=B / 12=B' / 13=C。stdout は現在の ref。
cmux_e2e_surface_resolve() {
  local reg id node type ref echoed
  reg=$(cmux_e2e_surface_registry_path)
  [[ -f "$reg" ]] || return 10
  id=$(jq -r '.surface_id // empty' "$reg") || return 10
  [[ -n "$id" ]] || return 10

  node=$("$CMUX_BIN" --json --id-format both tree --all \

    | jq -r --arg r "$ref" '[.windows[]?.workspaces[]?.panes[]?.surfaces[]? | select(.ref == $r) | .id] | first // empty')
  [[ -n "$id" ]] || cmux_e2e_die "could not resolve UUID for $ref" 1
  reg=$(cmux_e2e_surface_registry_path)
  cmux_e2e_mkdir_secure "$(dirname "$reg")"
  tmp="$reg.tmp.$$"
  printf '{"surface_id":"%s","surface_ref":"%s","worktree":"%s","created_at":"%s"}\n' \
    "$id" "$ref" "$(git rev-parse --show-toplevel)" "$(date -u +%Y-%m-%dT%H:%M:%SZ)" > "$tmp"
  cmux_e2e_install_file "$tmp" "$reg"
  printf '%s' "$ref"
}
```

```bash
#!/usr/bin/env bash
# auth-core.sh — 認証ステートの locked core。ロックは取らない（呼び出し側が保持する）。

cmux_e2e_auth_root() { printf '%s/%s/auth' "$(cmux_e2e_cache_root)" "$(cmux_e2e_project_key)"; }
cmux_e2e_auth_dir() { printf '%s/entries/%s' "$(cmux_e2e_auth_root)" "$1"; }
cmux_e2e_auth_lock_dir() { printf '%s/locks/%s' "$(cmux_e2e_auth_root)" "$1"; }

_cmux_e2e_digest() { shasum -a 256 "$1" | cut -d' ' -f1; }

_cmux_e2e_tab_count() {
  "$CMUX_BIN" --json browser --surface "$1" tab | jq '.tabs | length'
}

# auth_save_locked <ref> <name> <check_url> <check_selector>
auth_save_locked() {
  local ref="$1" name="$2" curl_="${3:-}" csel="${4:-}" dir tmp_state tmp_meta n
  cmux_e2e_validate_name "$name" || cmux_e2e_die "invalid auth name: $name" 2
  if { [[ -n "$curl_" ]] && [[ -z "$csel" ]]; } || { [[ -z "$curl_" ]] && [[ -n "$csel" ]]; }; then
    cmux_e2e_die "--check-url and --check-selector must be given together or not at all" 2
  fi
  n=$(_cmux_e2e_tab_count "$ref")
  [[ "$n" -eq 1 ]] || { echo "ERROR: auth save requires exactly 1 tab (found $n). Close the extra tabs first." >&2; return 1; }
  dir=$(cmux_e2e_auth_dir "$name")
  cmux_e2e_reject_symlink "$dir" || cmux_e2e_die "refusing to write through a symlink: $dir" 1
  cmux_e2e_mkdir_secure "$dir"
  tmp_state="$dir/.state.json.tmp.$$"; tmp_meta="$dir/.meta.json.tmp.$$"
  "$CMUX_BIN" browser --surface "$ref" state save "$tmp_state" >/dev/null || { rm -f "$tmp_state"; return 1; }
  jq -n --arg d "$(_cmux_e2e_digest "$tmp_state")" --arg u "$curl_" --arg s "$csel" \
        --arg t "$(date -u +%Y-%m-%dT%H:%M:%SZ)" \
        '{state_sha256:$d, check_url:(if $u=="" then null else $u end),
          check_selector:(if $s=="" then null else $s end), saved_at:$t}' > "$tmp_meta"
  cmux_e2e_install_file "$tmp_state" "$dir/state.json"
  cmux_e2e_install_file "$tmp_meta" "$dir/meta.json"
  return 0
}

# auth_load_locked <ref> <name> — digest 照合に成功した場合だけ load する。
auth_load_locked() {
  local ref="$1" name="$2" dir want got
  cmux_e2e_validate_name "$name" || cmux_e2e_die "invalid auth name: $name" 2
  dir=$(cmux_e2e_auth_dir "$name")
  [[ -f "$dir/state.json" ]] || { echo "ERROR: auth '$name' not found. Run 'auth save $name' first." >&2; return 1; }
  if [[ ! -f "$dir/meta.json" ]] || ! want=$(jq -er '.state_sha256' "$dir/meta.json" 2>/dev/null); then
    echo "ERROR: auth '$name' metadata is missing or unreadable. Re-run 'auth save $name'." >&2
    return 1
  fi
  got=$(_cmux_e2e_digest "$dir/state.json")
  [[ "$want" == "$got" ]] || { echo "ERROR: auth '$name' is inconsistent (interrupted save). Re-run 'auth save $name'." >&2; return 1; }
  "$CMUX_BIN" browser --surface "$ref" state load "$dir/state.json" >/dev/null || return 1
  return 0
}

# auth_check_locked <ref> <name> — load したうえで有効性を確認する。
auth_check_locked() {
  local ref="$1" name="$2" dir url sel
  auth_load_locked "$ref" "$name" || return 1
  dir=$(cmux_e2e_auth_dir "$name")
  url=$(jq -r '.check_url // empty' "$dir/meta.json")
  sel=$(jq -r '.check_selector // empty' "$dir/meta.json")
  if [[ -z "$url" || -z "$sel" ]]; then
    echo "WARN: auth '$name' has no check condition; validity was NOT verified." >&2
    return 0
  fi
  "$CMUX_BIN" browser --surface "$ref" goto "$url" >/dev/null || return 1
  if ! "$CMUX_BIN" browser --surface "$ref" wait --selector "$sel" --timeout-ms 15000 >/dev/null; then
    echo "ERROR: auth '$name' appears expired. Log in again and re-run 'auth save $name'." >&2
    return 1
  fi
  return 0
}

auth_list() {
  local root d name
  root="$(cmux_e2e_auth_root)/entries"
  [[ -d "$root" ]] || return 0
  for d in "$root"/*/; do
    [[ -d "$d" ]] || continue
    [[ -f "$d/state.json" && -f "$d/meta.json" ]] || continue
    name=$(basename "$d"); printf '%s\n' "$name"
  done
}

auth_delete_locked() {
  local name="$1" dir
  cmux_e2e_validate_name "$name" || cmux_e2e_die "invalid auth name: $name" 2
  dir=$(cmux_e2e_auth_dir "$name")
  [[ -d "$dir" ]] || { echo "auth '$name' does not exist; nothing to delete" >&2; return 0; }
  rm -rf -- "$dir"
  return 0
}
```

## CLI invocation rules

These are measured behaviors of `cmux` 0.64.22 that the wrapper handles for you. Follow them
whenever you call `cmux browser` directly.

| Rule | Why |
|------|-----|
| Always pass `--surface <ref>` as a flag | The first positional token is eaten as the surface. `cmux browser console list` fails because `console` is read as the surface. |
| Pass selectors, text and keys as flags | `--selector` / `--text` / `--key` avoid the positional ambiguity. |
| Branch on exit codes, never parse stderr as JSON | `--json` does not apply to errors; stderr is always `Error: <message>`. |
| Use `--timeout-ms`, never `--timeout` | Both are accepted; mixing them is a 1000x mistake. |
| Never run `import` without flags | It is destructive by default and imports every cookie from the default browser. |

`trace`, `screencast`, `viewport`, `network`, `offline` and `geolocation` return `not_supported`
because the surface is a WKWebView. Evidence is screenshots and snapshots only.

## CLI 呼び出しの規約

以下は `cmux` 0.64.22 の実測に基づく挙動で、ラッパーが肩代わりしている。`cmux browser` を
直接呼ぶときは自分で守ること。

| 規約 | 理由 |
|------|-----|
| 常に `--surface <ref>` をフラグで渡す | 第 1 位置引数は surface として食われる。`cmux browser console list` は `console` を surface と読むため失敗する。 |
| セレクタ・テキスト・キーもフラグで渡す | `--selector` / `--text` / `--key` を使えば位置引数の曖昧さが消える。 |
| 合否は exit code で分岐し、stderr を JSON として解析しない | `--json` はエラー出力に適用されず、stderr は常に `Error: <message>` である。 |
| `--timeout` ではなく `--timeout-ms` を使う | 両方受け付けるので、混在すると 1000 倍の取り違えになる。 |
| `import` を無引数で呼ばない | 既定が破壊的で、デフォルトブラウザの cookie をすべて取り込む。 |

`trace` / `screencast` / `viewport` / `network` / `offline` / `geolocation` は
サーフェスが WKWebView であるため `not_supported` を返す。証跡は screenshot と snapshot のみ。

## 認証

ログインの仕方、SSO / 2FA の扱い、`state save` / `state load` の意味は
`~/.agents/skills/cmux-browser/references/authentication.md` を読むこと。このスキルが足すのは
運用の層だけである。

1. `up` を実行し、表示されたサーフェスで実際にログインする（または

使い捨ての worktree が再ログインの手間にならず、gitignore の書き漏れで漏洩することもない。

## 失敗モード

| 状況 | 挙動 |
|-----------|----------|
| cmux CLI が見つからない | exit 1。cmux の中で実行すること。 |
| サーフェスが記録されていない | exit 1。`up` を促す。 |
| 記録されたサーフェスが消えている | `up` は作り直す。`run` は exit 1 で `up` を促す。 |
| サーフェスが別の ref として応答する | exit 1。別の画面を操作しないために中断する。 |

| シナリオが非ゼロ終了 | その終了コードを返す。証跡は収集する。 |
| シナリオは成功したが JS エラーが記録された | `--allow-js-errors` が無ければ exit 1。 |
