# cmux-e2e Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** cmux 内蔵ブラウザ（`cmux browser` CLI）を使った E2E テスト実行基盤を、新規プラグイン `apps/cmux-e2e` として追加する。

**Architecture:** bash のみのプラグイン。`skills/cmux-e2e/scripts/` に 4 本の CLI（`up` / `auth` / `run` / `down`）、`scripts/lib/` にロック・サーフェス解決・認証の locked core を置く。制御用の状態（サーフェスレジストリ・認証ステート・ロック）は `~/.cache/cc-skills/cmux-e2e/<project>/` に置き、成果物だけ worktree 内の `.cmux-e2e-results/` に置く。

**Tech Stack:** bash / git / jq / shasum / `cmux` CLI 0.64.22。`.dev-up.yaml` から project 名を読むときだけ `yq` を使う。

**Spec:** `docs/superpowers/specs/2026-08-25-cmux-e2e-design.md`

## Global Constraints

- `apps/e2e-test` に一切差分を出さない。並存させる
- `--engine cmux|agent-browser` のようなバックエンド切替を作らない
- `~/.agents/skills/cmux-browser` と役割を重複させない
- バージョンは `1.0.0`。plugin.json ×2 とルート `.claude-plugin/marketplace.json` の 3 箇所で一致させる
- `package.json` は作らない
- `SKILL.md` は frontmatter を除き日本語を含めない。`## Output Language` ブロックを frontmatter 直後・H1 より前に置き、本文 3 行を逐語一致させる。`references/guide-ja.md` を必ず用意する
- `CLAUDE.md` / `README.md` は日本語
- スクリプトは `#!/usr/bin/env bash`、mode 755、**終了コードは 2 = 使用法/検証エラー、1 = 実行時失敗、0 = 成功または無害な no-op**
- `cmux browser` は**常に `--surface <ref>` をフラグ形式**で渡す。セレクタ等も `--selector` / `--text` / `--key`
- 合否は exit code で分岐する。stderr を JSON として解析しない
- `wait` のタイムアウトは `--timeout-ms` に統一する
- **`cmux browser ... import` をどの経路からも呼ばない**
- `trace` / `screencast` / `viewport` / `network` / `offline` / `geolocation` は使わない
- ロックは `mkdir` の atomic 性だけに依存する。**stale ロックの自動回収はしない**
- 全ディレクトリ `0700` / 全ファイル `0600`。**秘密を作る前に `umask 077` を設定する**
- コミットは `<type>(cmux-e2e): <日本語の要約>` 形式。末尾に `。` を付けない

## 安全上の不変条件（全タスク共通）

実装中に次を破ってはならない。plan round 1 のレビューで実際に踏んだものである。

| # | 不変条件 |
|---|---------|
| S1 | **自分が取得していないロックを解放しない。** `cmux_e2e_lock_acquire` が成功したものだけを保持リストへ積み、cleanup はそのリストだけを解放する |
| S2 | **シグナルを捕捉したら必ず `exit` する。** ハンドラから戻ると bash は処理を続行し、ロックを解放したまま無排他で走る |
| S3 | **guard の有効・無効と対象 ref は生成時にラッパーへ literal で焼き込む。** 実行時の環境変数を判定材料にしない（シナリオが上書きできてしまう） |
| S4 | **`.env.dispatch` は data として読む。** `source` しない。予約名を拒否し、シナリオの子環境へ明示的に export する |
| S5 | **インフラ障害（CLI 失敗・JSON 破損・書き込み失敗）を「状態 A/B」と混同しない。** 別の rc にして fail-close する |
| S6 | **テストは一時 git リポジトリの中で行う。** 実 worktree の `.cmux-e2e-*` を作ったり消したりしない |
| S7 | **終了コードは最後に 1 回だけ決める。** 主因を先に確定し、証跡収集や summary の失敗で上書きしない |
| S8 | **cache root の内側であることと経路に symlink が無いことを、読み書き削除ロックの各入口で検証する** |

```bash
#!/usr/bin/env bash
# harness.sh — テストを一時 git リポジトリの中に隔離する土台。
# 実 worktree のファイルには決して触れない。

_H_FAIL=0
_H_TMP=""

h_setup() {
  _H_TMP=$(mktemp -d)
  export HOME="$_H_TMP/home"
  mkdir -p "$HOME"
  mkdir -p "$_H_TMP/repo"
  ( cd "$_H_TMP/repo" \
    && git init -q \
    && git config user.email t@example.com \
    && git config user.name t \
    && git commit -q --allow-empty -m init )
  cd "$_H_TMP/repo" || exit 1
  export CMUX_STUB_LOG="$_H_TMP/calls.log"; : > "$CMUX_STUB_LOG"
  export CMUX_STUB_TREE="$_H_TMP/tree.json"
  h_tree_empty
}

h_tmp() { printf '%s' "$_H_TMP"; }

# h_tree <uuid> <ref> <type> [<uuid2> <ref2> <type2> ...]
h_tree() {
  local out="" first=1
  while [[ $# -ge 3 ]]; do
    [[ "$first" -eq 1 ]] || out+=","
    first=0
    out+=$(printf '{"id":"%s","ref":"%s","type":"%s"}' "$1" "$2" "$3")
    shift 3
  done
  printf '{"windows":[{"workspaces":[{"panes":[{"surfaces":[%s]}]}]}]}\n' "$out" > "$CMUX_STUB_TREE"
}

h_tree_empty() { printf '{"windows":[{"workspaces":[{"panes":[{"surfaces":[]}]}]}]}\n' > "$CMUX_STUB_TREE"; }

h_check() {
  if [[ "$2" == "$3" ]]; then
    echo "ok   - $1"
  else
    echo "FAIL - $1: expected '$2' got '$3'"
    _H_FAIL=1
  fi
}

h_contains() {
  if [[ "$2" == *"$3"* ]]; then echo "ok   - $1"; else echo "FAIL - $1: '$2' lacks '$3'"; _H_FAIL=1; fi
}

h_mode() { stat -f '%Lp' "$1" 2>/dev/null || stat -c '%a' "$1"; }

# 共有ログに import が現れないこと。全テストの末尾で呼ぶ。
h_assert_no_import() {
  if grep -q 'import' "$CMUX_STUB_LOG"; then
    echo "FAIL - cmux browser import was called"; _H_FAIL=1
  else
    echo "ok   - import never called"
  fi
}

h_teardown() { cd /; [[ -n "$_H_TMP" ]] && rm -rf "$_H_TMP"; }
h_fail_count() { printf '%s' "$_H_FAIL"; }
```

```bash
#!/usr/bin/env bash
# common.sh — 鍵の解決、名前検証、パス封じ込め、パーミッション。
# このファイルは source される。

cmux_e2e_die() { echo "cmux-e2e: $1" >&2; exit "${2:-1}"; }

# 依存コマンドは差し替え可能にする。テストが「不在」を再現するために必要である
# (PATH を削ると shasum や git まで消えてしまい、対象だけを隠せない)。
CMUX_E2E_JQ="${CMUX_E2E_JQ:-jq}"
CMUX_E2E_YQ="${CMUX_E2E_YQ:-yq}"
CMUX_E2E_SHASUM="${CMUX_E2E_SHASUM:-shasum}"

# 秘密を作る全 CLI が最初に呼ぶ。外部コマンド (cmux state save) が作るファイルにも効かせる。
cmux_e2e_harden_umask() { umask 077; }

cmux_e2e_validate_name() {
  local n="${1-}"
  [[ -n "$n" ]] || return 2
  [[ "$n" != "." && "$n" != ".." ]] || return 2
  [[ "$n" =~ ^[A-Za-z0-9._-]+$ ]] || return 2
  return 0
}

_cmux_e2e_sha256_16() { printf '%s' "$1" | "$CMUX_E2E_SHASUM" -a 256 | cut -c1-16; }

cmux_e2e_worktree_key() {
  local root key
  root=$(git rev-parse --show-toplevel) || return 1
  root=$(cd "$root" && pwd -P) || return 1
  key=$(_cmux_e2e_sha256_16 "$root") || return 1
  [[ -n "$key" ]] || return 1
  printf '%s' "$key"
}

# .dev-up.yaml の project があればそれ。無ければ
# <git common dir の親ディレクトリ名>-<realpath(git common dir) の SHA-256 先頭 16 桁>。
# .dev-up.yaml があるのに yq が無い場合は黙って fallback せず失敗させる。
cmux_e2e_project_key() {
  local root common main key
  root=$(git rev-parse --show-toplevel) || return 1
  if [[ -f "$root/.dev-up.yaml" ]]; then

cmux_e2e_cache_root() { printf '%s/.cache/cc-skills/cmux-e2e' "$HOME"; }

# S8: 経路のどの構成要素も symlink でないことを、絶対 root から対象まで辿って確認する。
# 存在しない末端は許すが、存在する部分はすべて検査する。
_cmux_e2e_no_symlink_below() {
  local base="$1" target="$2" rel part cur
  [[ "$target" == "$base"* ]] || return 1
  [[ -L "$base" ]] && return 1
  rel="${target#"$base"}"; rel="${rel#/}"
  cur="$base"
  local IFS=/
  for part in $rel; do
    [[ -n "$part" ]] || continue
    [[ "$part" == "." || "$part" == ".." ]] && return 1
    cur="$cur/$part"
    [[ -L "$cur" ]] && return 1
  done
  return 0
}

# cache root 配下であり、経路に symlink も . / .. も無いこと。
# root 自身と、その上の $HOME/.cache や cc-skills も検査する。
cmux_e2e_secure_path() {
  local target="$1" root home_cache
  root=$(cmux_e2e_cache_root) || return 1
  home_cache="$HOME/.cache"
  [[ -L "$HOME" ]] && return 1
  _cmux_e2e_no_symlink_below "$HOME" "$root" || return 1
  case "$target" in "$root"/*) ;; *) return 1 ;; esac
  _cmux_e2e_no_symlink_below "$root" "$target" || return 1
  return 0
}

# worktree 内の成果物用。書き込み先が symlink や非 regular file なら拒否する。
cmux_e2e_secure_artifact() {
  local target="$1" root="$2"
  case "$target" in "$root"/*) ;; *) return 1 ;; esac
  _cmux_e2e_no_symlink_below "$root" "$target" || return 1
  [[ -e "$target" && ! -f "$target" && ! -d "$target" ]] && return 1
  return 0
}

# 作成し、cache root から対象までの全中間ディレクトリを 0700 へ矯正する。
cmux_e2e_mkdir_secure() {
  local d="$1" root rel part cur
  root=$(cmux_e2e_cache_root) || return 1
  cmux_e2e_secure_path "$d" || { [[ "$d" == "$root" ]] || return 1; }
  mkdir -p "$root" || return 1
  chmod 700 "$root" || return 1
  rel="${d#"$root"}"; rel="${rel#/}"
  cur="$root"
  local IFS=/
  for part in $rel; do
    [[ -n "$part" ]] || continue
    cur="$cur/$part"
    mkdir -p "$cur" || return 1
    [[ -L "$cur" ]] && return 1
    chmod 700 "$cur" || return 1
  done
  return 0
}

cmux_e2e_install_file() {
  local tmp="$1" dest="$2"
  chmod 600 "$tmp" || return 1
  mv -- "$tmp" "$dest" || return 1
  return 0
}

#!/usr/bin/env bash
# lock.sh — mkdir の atomic 性だけに依存するロック。自動回収はしない。
# owner.json は診断用であり、排他の判定には使わない。

_CMUX_E2E_HELD=()
_CMUX_E2E_CRITICAL=0
_CMUX_E2E_PENDING_SIG=""

# High 3: mkdir の成功と保持リストへの登録の間にシグナルが入ると、取得済みの
# ロックを cleanup が認識できず残してしまう。この区間ではハンドラを即 exit
# させず、シグナルを保留して区間を抜けてから処理する。
_cmux_e2e_enter_critical() { _CMUX_E2E_CRITICAL=1; }
_cmux_e2e_leave_critical() {
  _CMUX_E2E_CRITICAL=0
  if [[ -n "$_CMUX_E2E_PENDING_SIG" ]]; then
    local sig="$_CMUX_E2E_PENDING_SIG"; _CMUX_E2E_PENDING_SIG=""
    case "$sig" in INT) exit 130 ;; TERM) exit 143 ;; HUP) exit 129 ;; esac
  fi
}
_cmux_e2e_signal() {
  local sig="$1" code="$2"
  if [[ "$_CMUX_E2E_CRITICAL" -eq 1 ]]; then _CMUX_E2E_PENDING_SIG="$sig"; return 0; fi
  cmux_e2e_on_signal "$sig" "$code"
}
# 既定の動作。子プロセスを持つ CLI は上書きする。
cmux_e2e_on_signal() { exit "$2"; }

cmux_e2e_lock_acquire() {
  local dir="$1" tmp info esc rc
  cmux_e2e_secure_path "$dir" || { echo "ERROR: refusing to lock outside the cache root: $dir" >&2; return 1; }
  cmux_e2e_mkdir_secure "$(dirname "$dir")" || return 1
  _cmux_e2e_enter_critical
  if ! mkdir -m 700 "$dir" 2>/dev/null; then
    _cmux_e2e_leave_critical
    info="holder unknown"
    if [[ -f "$dir/owner.json" ]]; then
      info=$(jq -r '"pid=\(.pid // "?") started_at=\(.started_at // "?")"' "$dir/owner.json" 2>/dev/null) \
        || info="owner.json is unreadable"
    fi
    esc=$(printf '%q' "$dir")
    {
      echo "ERROR: could not acquire the lock ($info)."
      echo "  cmux-e2e never reclaims locks automatically."
      echo "  If no cmux-e2e command is running, remove it by hand:"
      echo "    rm -rf -- $esc"
    } >&2
    return 1
  fi
  _CMUX_E2E_HELD+=("$dir")   # 取得直後に登録する
  _cmux_e2e_leave_critical   # ここまで来れば cleanup が回収できる
  tmp="$dir/.owner.json.tmp.$$"
  if ! "$CMUX_E2E_JQ" -n --argjson pid "$$" \
        --arg wt "$(git rev-parse --show-toplevel 2>/dev/null || pwd)" \
        --arg at "$(date -u +%Y-%m-%dT%H:%M:%SZ)" \
        '{pid:$pid, worktree:$wt, started_at:$at}' > "$tmp"; then
    rm -f -- "$tmp"; _cmux_e2e_unhold "$dir"; rm -rf -- "$dir"; return 1
  fi
  if ! cmux_e2e_install_file "$tmp" "$dir/owner.json"; then
    rm -f -- "$tmp"; _cmux_e2e_unhold "$dir"; rm -rf -- "$dir"; return 1
  fi
  return 0
}

_cmux_e2e_unhold() {
  local drop="$1" d rest=()
  for d in ${_CMUX_E2E_HELD[@]+"${_CMUX_E2E_HELD[@]}"}; do
    [[ "$d" == "$drop" ]] || rest+=("$d")
  done
  _CMUX_E2E_HELD=(${rest[@]+"${rest[@]}"})
}

# 保持しているものだけを解放する。パスを引数に取らないのは意図的である。
cmux_e2e_lock_release_all() {
  local d
  for d in ${_CMUX_E2E_HELD[@]+"${_CMUX_E2E_HELD[@]}"}; do
    rm -rf -- "$d"
  done
  _CMUX_E2E_HELD=()
  return 0
}

# S2: シグナルを捕まえたら必ず exit する。EXIT trap が解放を担う。
# 呼び出し側が子プロセスを持つ場合は cmux_e2e_install_traps_with_child を使う。
cmux_e2e_install_traps() {
  trap 'cmux_e2e_lock_release_all' EXIT
  trap '_cmux_e2e_signal INT 130' INT
  trap '_cmux_e2e_signal TERM 143' TERM
  trap '_cmux_e2e_signal HUP 129' HUP
}

#!/usr/bin/env bash
# surface.sh — tree --all によるサーフェス解決。短 ref ではなく UUID を主キーにする。

CMUX_BIN="${CMUX_BIN:-cmux}"

# Critical 1: 内側の失敗を握り潰さないよう、必ず local へ代入して rc を確かめる。
cmux_e2e_surface_registry_path() {
  local root proj wk
  root=$(cmux_e2e_cache_root) || return 1
  proj=$(cmux_e2e_project_key) || return 1
  wk=$(cmux_e2e_worktree_key) || return 1
  [[ -n "$root" && -n "$proj" && -n "$wk" ]] || return 1
  printf '%s/%s/surfaces/entries/%s.json' "$root" "$proj" "$wk"
}

cmux_e2e_surface_lock_dir() {
  local root proj wk
  root=$(cmux_e2e_cache_root) || return 1
  proj=$(cmux_e2e_project_key) || return 1
  wk=$(cmux_e2e_worktree_key) || return 1
  [[ -n "$root" && -n "$proj" && -n "$wk" ]] || return 1
  printf '%s/%s/surfaces/locks/%s' "$root" "$proj" "$wk"
}

# rc 0 で成功。stdout が空なら「該当なし」、非空なら該当ノードの JSON。
# rc 20 は CLI 失敗または JSON 破損。
_cmux_e2e_find_node() {
  local id="$1" tree out
  tree=$("$CMUX_BIN" --json --id-format both tree --all) || return 20
  jq -e . >/dev/null 2>&1 <<<"$tree" || return 20
  out=$(jq -r --arg id "$id" \
    '[.windows[]?.workspaces[]?.panes[]?.surfaces[]? | select(.id == $id)] | first // empty | tojson' \
    <<<"$tree") || return 20
  printf '%s' "$out"
  return 0
}

# rc 0=解決 / 10=A / 11=B / 12=B' / 13=C / 20=インフラ障害。stdout は現在の ref。
cmux_e2e_surface_resolve() {
  local reg id node type ref echoed tmp rc
  reg=$(cmux_e2e_surface_registry_path) || return 20
  cmux_e2e_secure_path "$reg" || return 20
  [[ -f "$reg" ]] || return 10
  jq -e . "$reg" >/dev/null 2>&1 || return 20
  id=$(jq -r '.surface_id // empty' "$reg") || return 20
  [[ -n "$id" ]] || return 20

  node=$(_cmux_e2e_find_node "$id"); rc=$?
  [[ "$rc" -eq 0 ]] || return 20
  [[ -n "$node" ]] || return 11

  type=$(jq -r '.type // empty' <<<"$node") || return 20
  [[ -n "$type" ]] || return 20
  [[ "$type" == "browser" ]] || return 12

  ref=$(jq -r '.ref // empty' <<<"$node") || return 20
  [[ -n "$ref" ]] || return 20
  echoed=$("$CMUX_BIN" --json browser --surface "$ref" identify | jq -r '.surface_ref // empty') || return 20
  [[ -n "$echoed" ]] || return 20
  [[ "$echoed" == "$ref" ]] || return 13

  tmp="$reg.tmp.$$"
  jq --arg r "$ref" '.surface_ref = $r' "$reg" > "$tmp" || { rm -f "$tmp"; return 20; }
  cmux_e2e_install_file "$tmp" "$reg" || { rm -f "$tmp"; return 20; }
  printf '%s' "$ref"
  return 0
}

# 実 CLI の契約どおり、new は surface を取らない。
cmux_e2e_surface_create() {
  local profile="${1:-}" out ref node id reg tmp rc
  if [[ -n "$profile" ]]; then
    out=$("$CMUX_BIN" --json browser new --profile "$profile") || return 20
  else
    out=$("$CMUX_BIN" --json browser new) || return 20
  fi
  ref=$(jq -r '.surface_ref // empty' <<<"$out") || return 20
  [[ -n "$ref" ]] || return 20
  node=$("$CMUX_BIN" --json --id-format both tree --all \
    | jq -r --arg r "$ref" \
      '[.windows[]?.workspaces[]?.panes[]?.surfaces[]? | select(.ref == $r)] | first // empty | tojson') || return 20
  [[ -n "$node" ]] || return 20
  id=$(jq -r '.id // empty' <<<"$node") || return 20
  [[ -n "$id" ]] || return 20
  reg=$(cmux_e2e_surface_registry_path) || return 20
  cmux_e2e_secure_path "$reg" || return 20
  cmux_e2e_mkdir_secure "$(dirname "$reg")" || return 20
  tmp="$reg.tmp.$$"
  jq -n --arg id "$id" --arg ref "$ref" --arg wt "$(git rev-parse --show-toplevel)" \
        --arg at "$(date -u +%Y-%m-%dT%H:%M:%SZ)" \
        '{surface_id:$id, surface_ref:$ref, worktree:$wt, created_at:$at}' > "$tmp" || { rm -f "$tmp"; return 20; }
  cmux_e2e_install_file "$tmp" "$reg" || { rm -f "$tmp"; return 20; }
  printf '%s' "$ref"
  return 0
}

cmux_e2e_surface_close() { "$CMUX_BIN" close-surface --surface "$1" >/dev/null 2>&1; }

#!/usr/bin/env bash
# auth-core.sh — 認証ステートの locked core。ロックは取らない（呼び出し側が保持する）。

# Critical 1: 内側の失敗を握り潰さないよう、必ず local へ代入して rc を確かめる。
cmux_e2e_auth_root() {
  local root proj
  root=$(cmux_e2e_cache_root) || return 1
  proj=$(cmux_e2e_project_key) || return 1
  [[ -n "$root" && -n "$proj" ]] || return 1
  printf '%s/%s/auth' "$root" "$proj"
}
cmux_e2e_auth_dir() {
  local base
  base=$(cmux_e2e_auth_root) || return 1
  [[ -n "$base" ]] || return 1
  printf '%s/entries/%s' "$base" "$1"
}
cmux_e2e_auth_lock_dir() {
  local base
  base=$(cmux_e2e_auth_root) || return 1
  [[ -n "$base" ]] || return 1
  printf '%s/locks/%s' "$base" "$1"
}

_cmux_e2e_digest() { "$CMUX_E2E_SHASUM" -a 256 "$1" | cut -d' ' -f1; }
_cmux_e2e_tab_count() { "$CMUX_BIN" --json browser --surface "$1" tab list | jq '.tabs | length'; }

# 全入口で名前とパスを検証する。rc 2 は使用法エラー。
_cmux_e2e_auth_dir_checked() {
  local name="$1" dir
  cmux_e2e_validate_name "$name" || return 2
  dir=$(cmux_e2e_auth_dir "$name") || return 1
  [[ -n "$dir" ]] || return 1
  cmux_e2e_secure_path "$dir" || return 1
  printf '%s' "$dir"
}

auth_save_locked() {
  local ref="$1" name="$2" curl_="${3:-}" csel="${4:-}" dir tmp_state tmp_meta n
  dir=$(_cmux_e2e_auth_dir_checked "$name") || return $?
  if { [[ -n "$curl_" ]] && [[ -z "$csel" ]]; } || { [[ -z "$curl_" ]] && [[ -n "$csel" ]]; }; then
    echo "ERROR: --check-url and --check-selector must be given together or not at all" >&2
    return 2
  fi
  n=$(_cmux_e2e_tab_count "$ref") || { echo "ERROR: could not read the tab list" >&2; return 1; }
  [[ "$n" -eq 1 ]] || { echo "ERROR: 'auth save' requires exactly 1 tab (found $n). Close the extra tabs first." >&2; return 1; }
  cmux_e2e_mkdir_secure "$dir" || return 1
  tmp_state="$dir/.state.json.tmp.$$"; tmp_meta="$dir/.meta.json.tmp.$$"
  # 一時ファイルは entry と同じディレクトリに置く。別 FS だと rename が原子的でなくなる。
  if ! "$CMUX_BIN" browser --surface "$ref" state save "$tmp_state" >/dev/null; then
    rm -f "$tmp_state"; echo "ERROR: 'state save' failed" >&2; return 1
  fi
  jq -n --arg d "$(_cmux_e2e_digest "$tmp_state")" --arg u "$curl_" --arg s "$csel" \
        --arg t "$(date -u +%Y-%m-%dT%H:%M:%SZ)" \
        '{state_sha256:$d,
          check_url:(if $u=="" then null else $u end),
          check_selector:(if $s=="" then null else $s end),
          saved_at:$t}' > "$tmp_meta" || { rm -f "$tmp_state" "$tmp_meta"; return 1; }
  cmux_e2e_install_file "$tmp_state" "$dir/state.json" || { rm -f "$tmp_state" "$tmp_meta"; return 1; }
  cmux_e2e_install_file "$tmp_meta"  "$dir/meta.json"  || { rm -f "$tmp_meta"; return 1; }
  return 0
}

# digest 照合に成功した場合だけ load する。
auth_load_locked() {
  local ref="$1" name="$2" dir want got
  dir=$(_cmux_e2e_auth_dir_checked "$name") || return $?
  [[ -f "$dir/state.json" ]] || { echo "ERROR: auth '$name' not found. Run 'auth save $name' first." >&2; return 1; }
  if [[ ! -f "$dir/meta.json" ]] || ! want=$(jq -er '.state_sha256' "$dir/meta.json" 2>/dev/null); then
    echo "ERROR: auth '$name' metadata is missing or unreadable; the state was NOT applied. Re-run 'auth save $name'." >&2
    return 1
  fi
  got=$(_cmux_e2e_digest "$dir/state.json")
  [[ "$want" == "$got" ]] || {
    echo "ERROR: auth '$name' is inconsistent (interrupted save); the state was NOT applied. Re-run 'auth save $name'." >&2
    return 1
  }
  "$CMUX_BIN" browser --surface "$ref" state load "$dir/state.json" >/dev/null || return 1
  return 0
}

auth_check_locked() {
  local ref="$1" name="$2" dir url sel
  auth_load_locked "$ref" "$name" || return $?
  dir=$(cmux_e2e_auth_dir "$name")
  url=$(jq -r '.check_url // empty' "$dir/meta.json")
  sel=$(jq -r '.check_selector // empty' "$dir/meta.json")
  if [[ -z "$url" || -z "$sel" ]]; then
    echo "WARN: auth '$name' has no check condition; its validity was NOT verified." >&2
    return 0
  fi
  "$CMUX_BIN" browser --surface "$ref" goto "$url" >/dev/null || return 1
  if ! "$CMUX_BIN" browser --surface "$ref" wait --selector "$sel" --timeout-ms 15000 >/dev/null; then
    echo "ERROR: auth '$name' appears expired. Log in again and re-run 'auth save $name'." >&2
    return 1
  fi
  return 0
}

auth_list() {
  local base root d
  base=$(cmux_e2e_auth_root) || return 1
  root="$base/entries"
  cmux_e2e_secure_path "$root" || return 1
  [[ -d "$root" ]] || return 0
  for d in "$root"/*/; do
    [[ -d "$d" ]] || continue
    [[ -f "$d/state.json" && -f "$d/meta.json" ]] || continue
    basename "$d"
  done
}

auth_delete_locked() {
  local name="$1" dir
  dir=$(_cmux_e2e_auth_dir_checked "$name") || return $?
  [[ -d "$dir" ]] || { echo "auth '$name' does not exist; nothing to delete" >&2; return 0; }
  rm -rf -- "$dir"
  return 0
}

#!/usr/bin/env bash
# down.sh — サーフェスを破棄しレコードを消す。
# Usage: down.sh [--sweep]

set -uo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
# shellcheck source=./lib/common.sh
source "$SCRIPT_DIR/lib/common.sh"
cmux_e2e_harden_umask
# shellcheck source=./lib/lock.sh
source "$SCRIPT_DIR/lib/lock.sh"
# shellcheck source=./lib/surface.sh

usage() { echo 'usage: down.sh [--sweep]' >&2; exit 2; }

SWEEP=0
while [[ $# -gt 0 ]]; do
  case "$1" in
    --sweep) SWEEP=1; shift ;;
    *) usage ;;
  esac
done

LOCK=$(cmux_e2e_surface_lock_dir) || exit 1
cmux_e2e_install_traps
cmux_e2e_lock_acquire "$LOCK" || exit 1

REG=$(cmux_e2e_surface_registry_path) || exit 1
STATUS=0

if [[ -f "$REG" ]]; then
  REF=$(cmux_e2e_surface_resolve); rc=$?
  case "$rc" in
    0)
      if cmux_e2e_surface_close "$REF"; then
        rm -f -- "$REG"; echo "surface closed: $REF"
      else
        echo "ERROR: failed to close $REF; keeping the record so it can be retried." >&2
        STATUS=1
      fi ;;
    11) rm -f -- "$REG"; echo "the recorded surface is already gone; record removed" ;;
    12) echo "ERROR: the recorded surface is no longer a browser surface; keeping the record." >&2; STATUS=1 ;;
    13) echo "ERROR: the surface did not answer as itself; refusing to close another screen." >&2; STATUS=1 ;;
    10) echo "no surface recorded for this worktree; nothing to do" ;;
    *)  echo "ERROR: could not talk to cmux; keeping the record." >&2; STATUS=1 ;;
  esac
else
  echo "no surface recorded for this worktree; nothing to do"
fi

if [[ "$SWEEP" -eq 1 ]]; then
  ENTRIES=$(dirname "$REG")
  # High 7: current record が無いと resolver を通らないので、ここで必ず検査する。
  cmux_e2e_secure_path "$ENTRIES" || { echo "ERROR: refusing to sweep through an unsafe path: $ENTRIES" >&2; exit 1; }
  [[ -L "$ENTRIES" ]] && { echo "ERROR: $ENTRIES is a symlink" >&2; exit 1; }
  for f in "$ENTRIES"/*.json; do
    [[ -f "$f" ]] || continue
    [[ "$f" == "$REG" ]] && continue
    wt=$(jq -r '.worktree // empty' "$f" 2>/dev/null) || continue
    [[ -n "$wt" && ! -d "$wt" ]] || continue
    id=$(jq -r '.surface_id // empty' "$f" 2>/dev/null)
    if [[ -n "$id" ]]; then
      node=$(_cmux_e2e_find_node "$id") || { echo "WARN: could not query cmux while sweeping $f" >&2; continue; }
      if [[ -n "$node" ]]; then
        ref=$(jq -r '.ref' <<<"$node")
        cmux_e2e_surface_close "$ref" || { echo "WARN: could not close $ref; keeping $f" >&2; continue; }
      fi
    fi
    rm -f -- "$f"
    echo "swept orphan record: $f"
  done
fi

exit "$STATUS"
```

**環境の契約（S3 / S4）**:

- ラッパーには**対象 ref と guard の有効・無効を literal で焼き込む**。実行時の環境変数を見ない。
  シナリオが `CMUX_E2E_GUARD=0` を設定しても無効化できない
- `.env.dispatch` は `source` しない。`KEY=VALUE` の行だけを data として読み、
  **allowlist**（`COMPOSE_PROJECT_NAME` / `SLOT` / `PROJECT` / `*_PORT`）に載るものだけを
  `env -i` で組んだ子環境へ渡す。`WORKTREE_ROOT` や `RESULTS_DIR` は `.env.dispatch` からは

  denylist ではなく allowlist にするのは、`SHELLOPTS` / `BASHOPTS` / `PS4` / `BASH_ENV` / `ENV` /

- 存在するのに検査を通らない `.env.dispatch`（symlink や特殊ファイル）は「不在」と区別し、
  改竄の可能性があるものとして**中断する**
- `source` しない理由は 2 つある。予約名や cleanup 用の変数を上書きされないため（S4）と、
  `source` しただけでは `KEY=VALUE` が子プロセスへ引き継がれず、シナリオに `*_PORT` が届かないためである

## Subcommands

## CLI invocation rules

These are measured behaviors of `cmux` 0.64.22 that the wrapper handles for you. Follow them
whenever you call `cmux browser` directly.

| Rule | Why |
|------|-----|
| Always pass `--surface <ref>` as a flag | The first positional token is eaten as the surface. `cmux browser console list` fails because `console` is read as the surface. |
| Pass selectors, text and keys as flags | `--selector` / `--text` / `--key` avoid the positional ambiguity. |
| Branch on exit codes, never parse stderr as JSON | `--json` does not apply to errors; stderr is always `Error: <message>`. |
| Use `--timeout-ms`, never `--timeout` | Both are accepted; mixing them is a 1000x mistake. |
| Never run `import` without flags | It is destructive by default and imports every cookie from the default browser. |

`trace`, `screencast`, `viewport`, `network`, `offline` and `geolocation` return `not_supported`
because the surface is a WKWebView. Evidence is screenshots and snapshots only.

## Authentication

Read `~/.agents/skills/cmux-browser/references/authentication.md` for how to log in, handle
SSO/2FA, and what `state save`/`state load` do. This skill only adds the operational layer:

1. Run `up`, then log in by hand on the visible surface (or bring a session in with
   `cmux browser --surface <ref> import --from <browser> --to-profile <name> --non-interactive`).
2. Run `auth save <name> --check-url <url> --check-selector <css>`.
3. Pass `--auth <name>` to `run`. The state is verified before it is applied.

State lives outside the repository, under `~/.cache/cc-skills/cmux-e2e/<project>/auth/`, so a
disposable worktree does not cost you a re-login and a missing gitignore rule cannot leak it.

## Failure modes

| Situation | Behavior |
|-----------|----------|
| cmux CLI not found | Exit 1. Run inside cmux. |
| No surface recorded | Exit 1, hint to run `up`. |
| Recorded surface is gone | `up` recreates it; `run` exits 1 and asks for `up`. |
| Surface answers as a different ref | Exit 1. Refuses to drive another screen. |
| Lock is held or left behind | Exit 1 with the absolute path to remove and an `rm -rf` line. Locks are never reclaimed automatically. |
| Scenario name contains `/` or `.` | Exit 2. |
| Auth name is empty, `.`, `..`, or has other characters | Exit 2. A dot inside a name is fine. |
| Only one of `--check-url` / `--check-selector` given | Exit 2. |
| Saved state digest does not match, or metadata is missing | Exit 1 and the state is NOT loaded. |
| More than one tab open | Exit 1. Close the extras; re-save the state if it restores them. |
| Scenario exits non-zero | That exit code is returned; artifacts are still collected. |
| Scenario passes but JS errors were logged | Exit 1 unless `--allow-js-errors`. |

3. `.cmux-e2e-scenarios/<name>.sh` にシナリオを書く
4. `run <name> --auth <name>` で実行する。結果は `.cmux-e2e-results/<name>/` に集まる
5. 使い終わったら `down` で閉じる

## 前提条件

cmux の中で実行すること。追加のランタイム（Playwright など）は不要だが、
`bash` / `git` / `jq` / `shasum` は使う。`.dev-up.yaml` から project 名を読む場合のみ `yq` が要る。

**baseline は split の後に取る**。split 自体が terminal サーフェスを 1 つ増やすため、

  | jq -r --arg r "$1" '[.windows[]?.workspaces[]?.panes[]?.surfaces[]?|select(.ref==$r)|.id]|first//empty'; }

  | jq '[.windows[]?.workspaces[]?.panes[]?.surfaces[]?|select(.type=="browser")]|length'; }

[[ "$AFTER_N" -eq "$BEFORE_N" ]] || { echo "E5 FAIL: up created an extra browser surface ($BEFORE_N -> $AFTER_N)"; exit 1; }

## 実測に基づく主要な決定

- `cmux browser` は第 1 位置引数を surface として食うため、常に `--surface` をフラグで渡す
- サーフェスの同一性は短 ref ではなく UUID で判定し、探索は `tree --all` を使う
  （`list-pane-surfaces` は `--pane` 省略時にフォーカス中の pane しか返さない）
- `jq -e ... | first // empty` は該当なしで exit 4 を返すため、`jq -r ... | tojson` で
  「該当なし」と「jq の失敗」を分離する
- `trace` / `screencast` / `viewport` / `network` は WKWebView のため `not_supported`。
  証跡は screenshot と snapshot のみ
- `import` は無引数だと破壊的なので、どの経路からも自動で呼ばない
